# Create an interactive greeting script and improve it with input validation.

## Objective
Develop a shell script that greets the user and validates against empty input across separate commits.

## Commands Used
- `bash greeting.sh`
- `git add greeting.sh`
- `git commit -m "..."`
- `git diff`

## Expected Result
The script prompts for a name, greets the user on valid input, and warns if the input is empty.
