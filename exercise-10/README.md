# Demonstrate discarding unstaged changes and un-staging staged changes using git restore.

## Objective
Restore modified files from the staging area and discard working tree modifications using git restore.

## Commands Used
- `git add <file>`
- `git restore --staged <file>`
- `git restore <file>`
- `git status`

## Expected Result
Staged changes are un-staged using git restore --staged and working tree modifications are discarded using git restore.
