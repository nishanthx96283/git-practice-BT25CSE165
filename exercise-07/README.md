# Implement an interactive multi-option menu script on a feature branch and merge it into main.

## Objective
Develop a four-option interactive shell script within an isolated feature branch and merge it into the default branch.

## Commands Used
- `git checkout -b feature/menu`
- `bash menu.sh`
- `git add exercise-07/`
- `git commit -m "..."`
- `git checkout main`
- `git merge feature/menu`

## Expected Result
All four menu options execute correctly and the feature/menu branch merges cleanly into main.
