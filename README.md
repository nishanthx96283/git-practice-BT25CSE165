## About the Project

This assignment provides hands-on experience with Git through practical tasks. Each exercise is maintained in a separate directory with its own README and output file. The exercises demonstrate how to track changes, manage branches, resolve conflicts, and maintain a reliable project history.

## Git Workflow

The assignment covers the following core Git operations:

- Repository configuration and file tracking
- Staging and committing changes
- Comparing file versions
- Branch creation, merging, and cleanup
- Merge conflict resolution
- Restoring and reverting changes
- Stashing and recovering unfinished work
- Synchronizing commits with GitHub

For a quick command reference, see [git-commands.md](git-commands.md).
