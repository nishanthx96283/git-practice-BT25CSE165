# Demonstrate selective staging and separate commits for multiple files while leaving one file untracked.

## Objective
Stage and commit files independently to demonstrate granular version control while maintaining an untracked file.

## Commands Used
- `git status`
- `git add exercise-04/file1.txt`
- `git commit -m "..."`
- `git add exercise-04/file2.txt`

## Expected Result
Files are selectively staged and committed across separate commits, leaving the third file untracked.
